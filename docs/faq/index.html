Questions, answered.

Can't find your answer? Ask in our Discord server or open an issue on GitHub.

Will I get banned for using Vanta?

Client mods are against Discord's Terms of Service, so there's always some risk. In practice Discord doesn't go after people for using client mods. Avoid plugins that automate your account, and you'll be fine.

Vanta disappeared after Discord updated

Discord replaces its files when it updates. Vanta re-applies itself, and Vanta Guard (ticked by default in the installer) does it within seconds. If it's still gone, run the installer again and click Install.

Discord won't start or keeps crashing

If Discord fails to start twice in a row, Vanta starts in safe mode with no plugins or themes, and tells you why. You can also click Start in safe mode in the installer, then turn off the plugin that's causing it.

Can I use BetterDiscord themes?

Yes. Open Themes → Online to browse and install them in one click, or drop any .theme.css file into your themes folder. Only one theme is on at a time.

How do I install a plugin that isn't built in?

Use the Plugin Store, or go to Plugins → Import and pick a file or paste a link. Only install plugins from people you trust.

How do I keep my settings on another PC?

Turn on Cloud Sync in Vanta's settings. It saves your settings, Quick CSS, themes and plugins to a private GitHub Gist on your own account.

How do I update Vanta?

You don't have to. Vanta checks for updates when Discord starts, installs them, and shows you what changed.

How do I uninstall Vanta?

Run the installer and click Uninstall. Discord goes back to normal, and Vanta Guard is removed too.
