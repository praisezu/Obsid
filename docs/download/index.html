Installing on Windows

  1. Run VantaInstaller.exe. If Windows warns about an unknown publisher, choose More info → Run anyway.
  2. Pick your Discord and click Install. Leave Keep Vanta installed after Discord updates ticked.
  3. Open Settings → Vanta Settings in Discord, or press Ctrl+Shift+O anywhere.

Installing on macOS or Linux

  1. Open a terminal in the folder you downloaded the installer to.
  2. Run chmod +x VantaInstaller-*, then ./VantaInstaller-macos -install or ./VantaInstaller-linux -install.
  3. Restart Discord and open Settings → Vanta Settings.
