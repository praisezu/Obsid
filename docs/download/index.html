Download

Get the installer, pick your Discord and click Install. Discord restarts with Vanta, and updates come in automatically after that.

Windows

Graphical installer. Works with Stable, PTB and Canary.

Download VantaInstaller.exe

macOS

Paste this into Terminal. It picks Apple Silicon or Intel for you, checks the download, and installs.

curl -fsSL https://tryvanta.dev/install.sh | sh

Linux

Paste this into a terminal. It checks the download and installs.

curl -fsSL https://tryvanta.dev/install.sh | sh

Installing on Windows

  1. Run VantaInstaller.exe. If Windows warns about an unknown publisher, choose More info → Run anyway.
  2. Pick your Discord and click Install. Leave Keep Vanta installed after Discord updates ticked.
  3. Open Settings → Vanta Settings in Discord, or press Ctrl+Shift+O anywhere.

Installing on macOS or Linux

  1. Open Terminal (on a Mac: Spotlight → "Terminal").
  2. Paste curl -fsSL https://tryvanta.dev/install.sh | sh and press Enter. It downloads the right installer, checks it against the release checksum, and installs Vanta into Discord.
  3. Restart Discord and open Settings → Vanta Settings.

Why a command instead of a download? Browsers mark downloads as "from the internet", and macOS then blocks apps that aren't signed by an Apple developer account. Downloading with curl skips that, and the script checks the file itself. You can read the script first. Prefer a file? Get Apple Silicon, Intel Mac or Linux, then on a Mac right-click it → Open the first time.
