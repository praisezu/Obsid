Vanta

A Discord client mod with 100+ plugins, BetterDiscord themes, a plugin store and automatic updates. Fast, and nothing runs unless you turn it on.

What you get

Everything lives in its own section of Discord's settings.

100+ plugins

See deleted and edited messages, translate, read all, hide clutter, custom status, platform icons and much more.

Themes

Browse and install BetterDiscord themes in one click, or make your own with the built-in theme editor.

Plugin Store

Official plugins plus community plugins, each checked before it's listed and locked to the reviewed version.

Stays installed

Vanta Guard puts Vanta back automatically after Discord updates itself.

Safe mode

If a plugin ever breaks Discord, Vanta starts without plugins so you can fix it.

Cloud sync

Keep your setup the same on every PC with a private GitHub Gist on your own account.

Auto-updates

New versions install themselves and tell you what changed.

Light on your PC

Plugins that are off cost nothing; most appearance tweaks are pure CSS.

Built-in plugins

Every one is off until you switch it on.

Install

  1. Download VantaInstaller.exe and run it. Windows may warn about an unknown publisher; choose More info → Run anyway.
  2. Pick your Discord and click Install. Discord restarts with Vanta.
  3. Open Settings → Vanta Settings, or press Ctrl+Shift+O anywhere.

macOS and Linux: download the installer for your system and run VantaInstaller -install in a terminal.
