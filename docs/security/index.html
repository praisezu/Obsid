Security

What Vanta can do, what it never does, and everything it connects to. Vanta is open source, so you can check all of this in the code.

The short version

  1. No tracking. Vanta has no analytics, no telemetry and no Vanta servers. Nothing about you is collected.
  2. Your account stays yours. Vanta never reads your login token for itself, and its token guard stops plugins you install from reading it or sending it anywhere.
  3. Everything runs on your PC. Settings, plugins, themes, bookmarks and Capri's memory are files in your Vanta folder.
  4. Anything online is either needed (updates) or switched on by you (themes, the plugin store, Capri's online brain).

What Vanta can access

Like every Discord mod, Vanta runs inside Discord, so it has the same access the Discord app has: your messages, servers and account actions. That's why who you trust matters:

  1. Built-in plugins are part of Vanta and open source. They only do what they say, and they're off until you turn them on.
  2. Store plugins are reviewed before they're listed, and each one is pinned to the exact reviewed file (by its SHA-256 hash): if it changes, Vanta refuses to install it. Only plugins with the Official badge are made by Vanta.
  3. Plugins you import yourself get a warning before installing, which flags code that mentions your token, makes network requests or runs hidden code. Only import plugins from people you trust.

Protection that's always on

  1. Token-grabber guard. Your login token lets anyone take over your account. If a plugin you installed asks Discord for it, Vanta refuses and tells you which plugin tried. Any request leaving for a website that isn't Discord with your token in it is stopped, whoever sent it.
  2. Scam link checker. Links to known Discord scam and phishing sites (fake Nitro, fake logins, fake giveaways) get a warning before they open. The list is the public Discord-AntiScam list, downloaded once a day and checked on your PC; your clicks aren't sent anywhere.
  3. Crash shield and safe mode. A plugin that keeps failing is switched off, and if Discord can't start twice in a row, Vanta starts without plugins or themes.

Every website Vanta talks to

github.com updates

Checks for and downloads Vanta updates (the official releases). Store plugins, the scam list and Capri's art come from the same repositories on raw.githubusercontent.com.

betterdiscord.app themes

Only when you browse or install themes in Themes → Online.

huggingface.co · cdn.jsdelivr.net Capri

Only if Capri speaks or uses her offline brain: her voice and brain models download once (pinned, hash-checked libraries) and then run on your PC.

Pollinations · NVIDIA · Anthropic opt-in

Only if you let Capri think online. What you type to her and short notes about what's happening (channel names, songs) go to the AI you picked. With an NVIDIA or Claude key, only that company is used.

translate.googleapis.com opt-in

Only when you translate a message with the Translate plugin.

Discord always

Discord itself, as normal. Plugins that act for you (like Capri sending a message you confirmed) use Discord's own API as you.

Honest limits

  1. Client mods break Discord's Terms of Service. Bans for using one are rare, but the risk isn't zero.
  2. No guard is perfect. The token guard stops the common ways plugins steal tokens, but a determined malicious plugin has the same access Discord does. Installing only trusted plugins is still the real protection.
  3. Unsigned downloads. Until code signing is in place, Windows may warn about an "unknown publisher", and Mac users should use the install command on the Download page.

Found a security problem?

Please report it privately through GitHub's private vulnerability reporting rather than a public issue. You'll get a reply, and fixes ship as a normal update.
